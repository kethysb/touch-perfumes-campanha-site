# Touch Perfumes Campanha Site

Site estático de campanha para perfumes Touti, com foco em conversão via WhatsApp.

## Principal

- Promoção: 5 perfumes por R$199,90.
- Valor por unidade no kit: R$39,98.
- WhatsApp da campanha: 19 98207-5633.
- Página principal: `index.html`.

## Arquivos úteis

- `index.html`: versão final publicada.
- `index-stitch.html`: cópia da versão final gerada a partir do design Stitch.
- `index-original.html`: versão anterior preservada.
- `BRIEFING_CAMPANHA_TOUTI_WHATSAPP.md`: briefing com informações comerciais e direção de copy.
- `assets/`: imagens e vídeos usados no site.
- `previews/`: capturas desktop/mobile geradas durante validação.
